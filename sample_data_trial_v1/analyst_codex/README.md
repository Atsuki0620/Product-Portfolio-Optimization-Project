# analyst_codex ディレクトリ概要

本フォルダは、project_spec.md に基づく sample_data_trial_v1 初回トライアル業務を記録・実装する専用領域です。他担当への影響を避けるため、ドキュメント・スクリプトはすべてここで管理します。

## 現在の構成
- `00_setup_notes.md`: リポジトリ共通方針および仕様書の要点整理。
- `01_data_requirements.md`: 必要データセットとカラム仕様・前提条件の定義。
- `02_processing_flow.md`: Phase1〜3 におけるデータ整形と最適化処理フロー設計。
- `03_validation_and_outputs.md`: Phase4/8 の検証手順・感度分析・成果物テンプレート。
- `notebooks/` (予定): 実装用 Jupyter Notebook もしくはスクリプトを配置予定。

## 今後の進め方
1. 上記ドキュメントを内容充実させながら、必要なサンプルデータの作成方針を固める。
2. notebooks ディレクトリを作成し、データ準備ノート (`01_data_prep.ipynb` など) を順次追加する。
3. 粗利最大化ロジックと貪欲配賦アルゴリズムを Python で実装し、検証結果を 03 ドキュメントに反映する。
