# 利益最大化のための製品構成比率分析：仮想サンプルデータ初回トライアル計画

本ドキュメントは、仮想サンプルデータ（20製品×8セグメント×2拠点、過去3年分）を用いた初回トライアルの計画と、プロジェクト仕様書の原文をまとめたものです。

## ステップ別計画
1. データ収集と検証：販売実績・生産実績・制約条件データの項目チェック、欠損や整合性の確認。
2. データ整形と集計：製品×拠点×セグメント単位で販売数量・金額・平均販売単価を集計し、製造原価率を整理。
3. 粗利計算と需要設定：単位粗利・粗利率を算出し、過去3年平均から需要および受注可能数量を設定。
4. 優先順位付け：単位粗利が高い製品×拠点×セグメント組み合わせを抽出し、過去実績のあるパターンに限定。
5. 最適配分試算：拠点別生産能力を上限として貪欲配分を行い、総粗利と構成比率を算出。
6. 現状対比と効果測定：現行構成との比較で利益増加額・増減するセグメントを特定。
7. 実行可能性レビュー：営業・製造・集中リスクの観点で実現性を確認。
8. 感度分析：需要±10%、原価±5%、販売単価±5%のシナリオで変動を評価。

# プロジェクト仕様書（原文）

## 1. プロジェクト概要

### 背景・目的

- **依頼者**：事業部長
- **課題認識**：ポートフォリオの見直し。どのセグメントに注力すべきか明確でない
- **目的**：利益（粗利）を最大化するための生産製品構成比率を分析し、最適解を導出する
- **分析期間**：過去3年分の実績データを使用（年間粒度、季節性は考慮しない）

### アウトプット

1. **現状分析**：過去3年の構成比率と収益性
1. **最適解**：推奨する製品構成比率と期待利益
1. **改善効果**：現状から最適解への移行で得られる利益増加額
1. **実行プラン**：どのセグメントを増やし、どれを減らすか

## 5. データ構造

### 5.1 必要なデータ項目

**販売実績データ（明細レベル・過去3年分）**

- 年度
- 製品名
- 生産拠点（A or B）
- セグメント区分（1〜8）
- 販売数量
- 販売金額
- 顧客名（参考情報）

**生産実績データ（過去3年分）**

- 年度
- 製品名
- 生産拠点（A or B）
- 生産数量
- 製造原価総額

**制約条件データ**

- 各拠点の年間生産能力：528,000本/拠点
- 合計：1,056,000本/年

### 5.2 データの特性・複雑性

1. **製品×拠点×セグメントの組み合わせ**

- 同一製品でも拠点により原価が異なる
- 同一製品でもセグメントにより販売単価が異なる
- 同一製品×拠点でも複数セグメントに販売される

1. **セグメント識別の難しさ**

- 製品名だけではセグメント判別不可
- 顧客名だけでもセグメント判別不可（代理店経由の場合）
- 販売時に用途情報として記録されている前提

1. **生産拠点の紐付け**

- 販売実績に「どの拠点で生産したか」の情報が必要
- ない場合は生産実績の比率で按分

## 6. 分析手法・計算ステップ

### Phase 1：過去データの整理と基礎分析

**Step 1：販売実績を製品×拠点×セグメント単位で集計**

```
過去3年分から：
- 製品×拠点×セグメントごとに販売数量・金額を集計
- 平均販売単価 = 販売金額 ÷ 販売数量
```

**Step 2：製造原価の整理**

```
製品×拠点ごとに：
- 単位製造原価 = 製造原価総額 ÷ 生産数量
- 3年間の平均を算出
```

**Step 3：粗利の算出**

```
製品×拠点×セグメントごとに：
- 単位粗利 = 平均販売単価 - 単位製造原価
- 粗利率 = 単位粗利 ÷ 平均販売単価 × 100
```

**Step 4：セグメント別の需要予測**

```
各セグメントについて：
- 需要予測 = 過去3年間の販売数量平均
- 受注可能数量 = 過去3年間の販売数量平均
```

**Step 5：生産能力の実績分析**

```
各拠点について：
- 実績稼働率を確認（現状90%）
- 現実的な生産能力上限を設定
```

### Phase 2：最適化のための製品グルーピング

**Step 6：製品×拠点×セグメントの組み合わせをランク付け**

```
全組み合わせについて：
- 単位粗利の大きい順にソート
- 過去3年で実績のない組み合わせは除外
```

※同じ製品でも以下は別の選択肢：

- 拠点Aで作ってセグメント1に売る
- 拠点Bで作ってセグメント1に売る
- 拠点Aで作ってセグメント2に売る

### Phase 3：最適配分の計算

**Step 7：制約条件の整理**

```
各製品×拠点×セグメントの組み合わせについて：
- 配分可能数量 = 過去3年の販売数量平均
```

**Step 8：拠点ごとの最適化**

```
【拠点A】
残生産能力_A = 528,000本

単位粗利の高い順に（拠点Aで生産する組み合わせのみ）：
  配分数量 = MIN(配分可能数量, 残生産能力_A)
  この製品×セグメントへの配分 = 配分数量
  残生産能力_A -= 配分数量

【拠点B】も同様
```

**Step 9：全社最適解の算出**

```
全社総粗利 = 拠点Aの総粗利 + 拠点Bの総粗利
セグメント別の構成比率を算出
```

### Phase 4：検証と実行可能性の確認

**Step 10：過去実績との比較**

```
比較項目：
- セグメント別構成比率
- セグメント別粗利
- 全社粗利
- 改善余地の算出
```

**Step 11：実現可能性の評価**

- 大幅に増やすセグメント：営業体制で対応可能か
- 大幅に減らすセグメント：顧客関係上問題ないか
- 製品別の偏りチェック

**Step 12：感度分析**

```
シナリオ：
- セグメント別需要±10%
- 製造原価±5%
- 販売価格±5%
```

## 7. 実務上の考慮点

### 7.1 定量分析だけでなく考慮すべき要素

- **顧客関係**：低粗利でも戦略的に重要な顧客・セグメント
- **製造の切り替えコスト**：頻繁な製品切り替えの影響
- **長期的な市場ポジション**：短期利益のための撤退リスク

### 7.2 営業利益ではなく粗利を使用

- 粗利 = 販売価格 - 製造原価
- 営業利益（販管費控除後）は使用しない

## 9. 制約・前提事項

### データの前提

- 販売実績にセグメント情報が記録されている
- 販売実績に生産拠点情報が紐付いている（または推定可能）
- 過去3年間のデータは信頼できる

### 分析の前提

- 来年の需要予測は過去3年平均を使用（予測モデルは使わない）
- 受注可能数量も過去3年平均を使用
- 季節性は考慮しない（年間粒度のみ）
- トレンドはほぼ横ばい（±5%）

### 最適化の前提

- 粗利最大化を目標とする
- 生産能力、需要、受注可能数量が制約条件
- 拠点間での製品移管コストは考慮しない（単純に原価差のみ）

## 10. 用語定義

|用語         |定義                  |
|-----------|--------------------|
|セグメント      |業界別の用途区分（8種類）       |
|製品         |製品名単位での区分（200製品）    |
|製品×拠点×セグメント|最小分析単位の組み合わせ        |
|単位粗利       |販売単価 - 単位製造原価       |
|粗利率        |単位粗利 ÷ 販売単価 × 100   |
|配分可能数量     |セグメント別の需要または受注可能数量  |
|最適解        |生産能力制約下で粗利を最大化する製品構成|
