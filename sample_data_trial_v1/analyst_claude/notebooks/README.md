# notebooks ディレクトリガイド

## 目的
Jupyter Notebook（もしくはVS Code Pythonノート）でのデータ整形・最適化検証を蓄積します。処理フローは `02_processing_flow.md` と同期し、手順ごとにノートを分割します。

## 推奨ファイル構成
1. `01_data_prep.ipynb`
   - D1/D2/D3 の読み込み、集計、粗利計算を実装。
   - ログ: 入力行数、欠損件数、平準化後の件数をMarkdownセルに記録。
2. `02_allocation.ipynb`
   - 貪欲配分アルゴリズム、キャパシティ検証、構成比算出。
   - 拠点別残キャパとセグメント需要残をグラフ化。
3. `03_sensitivity.ipynb`
   - 感度分析シナリオごとの再計算と比較表出力。

## 運用ルール
- Notebook で実行したコマンド/検証結果は `logs/` へJSON or CSVでエクスポート予定。
- データパスは `../data/*.csv` を基準に相対指定する。
- 版管理のため、大きな出力（データフレーム全量など）は極力Notebookに保存しない。
