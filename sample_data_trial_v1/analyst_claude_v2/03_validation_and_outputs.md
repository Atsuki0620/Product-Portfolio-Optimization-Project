# 03_validation_and_outputs

Phase4における検証方針、感度分析、成果物テンプレートを定義する。

## 1. 検証観点（Phase4）

Phase1〜3で算出した最適配分結果を以下の観点から検証し、実務展開の可能性を評価する。

### 1.1 定量検証
- **構成比の妥当性**: 現状と最適化後のセグメント別構成比を比較し、大幅な変動がないかを確認
- **粗利改善効果**: 現状粗利と最適化後粗利の差分を算出し、改善余地を定量化
- **キャパシティ使用率**: 各拠点の残余キャパシティを確認し、過度な負荷がないかを検証
- **需要充足率**: セグメント別に需要がどの程度充足されているかを確認

### 1.2 定性検証
- **営業実行可能性**: 現状から大きく構成比が変わる場合、営業体制で対応可能か
- **製造実行可能性**: 段取り替え回数の増加、技術者アサインの変更が現実的か
- **顧客関係への影響**: 低粗利セグメントを縮小する場合、顧客関係上問題がないか
- **リスク分散**: 特定セグメント・拠点への依存度が高まりすぎていないか

### 1.3 感度分析の必要性
外部環境変化に対する頑健性を確認するため、以下のシナリオで再計算を実施：
- 需要変動: ±10%
- 製造原価変動: ±5%
- 販売価格変動: ±5%

## 2. Phase4の実行ステップ

### Step 10: 過去実績との比較
1. 現状構成比と最適化後構成比の差分算出
2. セグメント別の数量・粗利変化の可視化
3. 拠点別の稼働率変化の確認
4. 改善効果の定量化（利益増加額）

### Step 11: 実現可能性の評価
1. 営業部門ヒアリング（構成比変更の受容可能性）
2. 製造部門ヒアリング（生産計画変更の実現性）
3. 物流・在庫部門ヒアリング（リードタイム・在庫への影響）
4. リスク評価（単一依存度、顧客関係悪化リスク）

### Step 12: 感度分析
1. シナリオ定義（需要・原価・価格の変動パターン）
2. シナリオ別の再配分実行
3. 総粗利・構成比への影響評価
4. 最悪シナリオでの対応策検討

## 4. 現状対比と効果測定（Step10）

### 4.1 数量・粗利の比較

|指標|現状（過去3年平均）|最適案（貪欲配賦）|差分|
|----|-------------------|-------------------|----|
|年間販売数量|6,732 本|6,732 本|±0|
|総粗利|72,922,961円|10,511,127円|-62,411,834円 ※|

※ **重要な注意**: この差分は「最適化により粗利が減少した」ことを意味するのではなく、**計算方法の相違**による見かけ上の差異である。詳細は `phase1_summary.md` のセクション6.3「粗利差異の詳細分析」を参照。

**差異の要因**:
- **ベースライン（現状）**: 過去3年間の実績販売金額と実績製造原価の実測値を使用（変動要因すべて含む）
- **最適化後**: 過去3年平均の単価・原価を使用（標準化された理論値）

**本質的な評価指標**: 構成比の変化（下記参照）

### 4.2 セグメント別構成比の比較

|セグメント|現状構成比|最適構成比|差分|
|---------|---------|---------|-----|
|automotive|17.14%|17.14%|±0.00%|
|chemical|15.08%|15.08%|±0.00%|
|construction|13.56%|13.56%|±0.00%|
|consumer|20.60%|20.60%|±0.00%|
|electronics|11.33%|11.33%|±0.00%|
|food_beverage|2.84%|2.84%|±0.00%|
|medical|3.64%|3.64%|±0.00%|
|others|15.82%|15.82%|±0.00%|

**解釈**:
- セグメント構成比は現状と最適がほぼ一致（サンプルデータでは需要上限=過去実績のため）
- 本番データでは需要余地があるセグメントに配賦を広げる前提
- 重点観点：粗利率上位の「電機・電子」「医療・ヘルスケア」は受注余地（残需要）がゼロのため、追加需要獲得策を営業側で検討する必要がある

**報告書での記載方針**:
- 上表＋`allocation_segment_summary.csv`を引用
- 現状比で差分ゼロとなった理由（需要上限＝実績）を明記
- 本番データでの期待効果を別途試算

### 4.3 拠点別配分の比較

|拠点|割当数量|割当粗利|稼働率|現状比|
|---|--------|-------|-----|-----|
|A（国内）|4,909本|8.76M|1.03%|±0%|
|B（海外）|1,823本|1.75M|0.38%|±0%|

**発見**:
- 拠点Aが全体の73%を担当（原価優位性により選択される）
- サンプルデータでは稼働率が1%未満と極めて低い
- 本番データでは稼働率90%に達する見込みで、拠点間トレードオフが顕在化

## 5. 実行可能性レビュー（Step11）

### 5.1 チェックリスト

|観点|チェック内容|ステータス/対応策|
|----|------------|----------------|
|営業体制|構成比を維持したまま粗利率の高い案件を優先受注できるか。低粗利セグメントの縮小余地は？|自動車・一般消費財は主力顧客の取引維持が必要。短期的には減らさず、追加需要獲得で粗利改善を狙う方針。|
|製造/生産|段取り替え・在庫負荷。高価格品を増やす場合の技術者アサイン。|高価格品（医療・電機）は拠点B/Aで既存体制あり。段取り替え回数は据え置きのため、現段階で追加投資不要。|
|物流/在庫|海外拠点Bのリードタイムと在庫リスク。|B拠点の出荷量は1,823本で現行と同程度。安全在庫の増減は不要だが、需要拡大時に補充リードタイムを再確認する。|
|リスク/依存|特定セグメント依存度の増減。|サンプルでは構成比が現状同等。今後需要余地が生じた際は、セグメント別売上RAG管理と併せてリスク分散策を提示する。|
|顧客関係|主要顧客への影響。値上げ・数量調整の受容性。|現状維持のため、顧客への説明負担なし。ただし、価格改定時には事前交渉が必須。|
|技術/品質|製品切替による品質リスク。新製品投入の技術的課題。|既存製品の組み合わせ変更のみのため、品質リスクは低い。新製品は別途品質保証プロセスを経る。|

### 5.2 推奨アクション（部門別）

**営業部門**:
1. 医療・電機セグメントの営業パイプライン拡大（目標: 各+20%）
2. 自動車セグメントでの高粗利製品へのアップセル活動
3. 一般消費財での値上げ交渉（粗利率+3%ポイント目標）

**製造部門**:
1. 拠点Bの稼働率向上施策（海外拠点の有効活用）
2. 高価格品の拠点間製造移管の検討（原価削減効果の試算）
3. 段取り替え最適化による生産効率向上

**経営企画部門**:
1. セグメント別売上のRAG（Red-Amber-Green）管理導入
2. 価格改定シナリオの検討（医療・電機で+5〜7%）
3. 本番データでの再評価スケジュール策定

## 6. 感度分析の洞察と推奨アクション

### 6.1 シナリオ別影響まとめ

|シナリオ|総粗利|ベース比|変動率|影響度|
|-------|------|-------|------|-----|
|Base（基準）|10.51M|±0M|0.00%|-|
|DemandPlus10|10.93M|+0.42M|+4.00%|中|
|DemandMinus10|9.98M|-0.53M|-5.04%|中|
|CostPlus5|9.82M|-0.69M|-6.56%|**大**|
|CostMinus5|11.20M|+0.69M|+6.56%|**大**|
|PricePlus5|11.73M|+1.21M|+11.53%|**最大**|
|PriceMinus5|9.30M|-1.21M|-11.53%|**最大**|

### 6.2 主要な洞察

#### 6.2.1 価格感応度が最大の影響要因
- **発見**: `PricePlus5` で総粗利 +1.21M、`PriceMinus5` で -1.21M と、単価5%変動で約±11%の粗利差
- **解釈**: 価格戦略が粗利に与える影響が圧倒的に大きい
- **対応**: 価格改定シナリオを想定し、医療・電機の値上げ許容度を検証する必要あり

#### 6.2.2 コスト上振れへの対策
- **発見**: `CostPlus5` で総粗利 -0.69M（-6.6%）
- **解釈**: 原材料費高騰・為替円安のリスクシナリオ
- **対応**: 拠点Bのユーティリティ費や原材料費をモニタリングし、早期に転嫁/効率化策を打つ

#### 6.2.3 需要変動への頑健性
- **発見**: `DemandPlus10` でも総粗利益の伸びは +0.42M に留まる（需要上限=実績のため）
- **解釈**: 高粗利セグメント（medical, electronics）の需要上限に達し、低粗利セグメントで数量を吸収
- **対応**: 今後、本番データで需要余地が可視化された場合は、追加需要を高粗利セグメントへ優先割当するルールを整備する

### 6.3 推奨アクション（優先度順）

#### 優先度1: 価格改定戦略（PricePlus5を目指す）
1. `run_scenarios_once.py` の結果をスライド化し、価格・コストの想定レンジに対する粗利レンジを共有
2. 医療セグメント新規製品で+7%の価格設定（Q1実施）
3. 電機セグメント既存製品で+5%の価格改定通知（Q2実施）
4. 自動車セグメント主要顧客との価格交渉（+2%目標、Q3実施）

**期待効果**: 総粗利+1.21M → 実現可能性80%で+0.97M

#### 優先度2: コスト削減戦略（CostMinus5を目指す）
1. 価格改定が難しいセグメント向けには、製造原価の5%削減（歩留まり改善等）をKPI化する
2. 拠点Bのエネルギー使用量削減プロジェクト（目標: -5%）
3. サプライヤー統合による調達コスト削減（-3%目標）

**期待効果**: 総粗利+0.69M → 実現可能性60%で+0.41M

#### 優先度3: 需要拡大戦略（DemandPlus10を目指す）
1. 需要余地が出た場合に備え、医療/電機向けの営業パイプライン拡大計画を別途検討する
2. 医療セグメント: 新規病院グループへの提案活動強化
3. 電機セグメント: 新製品投入による市場シェア拡大

**期待効果**: 総粗利+0.42M → 営業コスト増を考慮すると純増+0.25M程度

### 6.4 最悪シナリオへの備え
**想定**: 価格競争激化（PriceMinus5）+ 原価上昇（CostPlus5）の組み合わせ
- 総粗利への影響: -1.21M - 0.69M = **-1.90M（-18%）**
- 対応策:
  1. 緊急コスト削減プロジェクトの発動
  2. 低粗利セグメントからの段階的撤退検討
  3. 高付加価値製品への集中投資

## 8. 次フェーズへの引継ぎ事項

### 8.1 本番データ適用時の留意点
1. データ規模が35倍に拡大（20製品 → 200製品）
2. キャパシティ制約が顕在化し、セグメント間トレードオフが発生
3. 需要予測の精緻化（過去平均 → トレンド分析）が必要
4. 月次更新の運用プロセス確立が必要

### 8.2 継続モニタリング項目
- セグメント別粗利率の月次推移
- 拠点別稼働率の週次推移
- 価格・原価の変動トレンド
- 主要顧客の発注パターン変化

### 8.3 改善・拡張の余地
- 季節性の考慮（四半期別最適化）
- 複数年の最適化（中期経営計画との連動）
- リアルタイムダッシュボード構築
- 機械学習による需要予測モデル導入
