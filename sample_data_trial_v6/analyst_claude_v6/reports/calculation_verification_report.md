## 質問1と2: oil_gasセグメントの計算（Step2）

### 入力データ（market_master.csvより）

```
segment_code: oil_gas
market_size: 756,000本
market_size_after_1y: 793,800本
cagr: 0.05 (5%)
current_share: 0.2 (20%)
strategy_type: aggressive_expansion
```

### ステップ1: 戦略係数の適用

**戦略係数範囲**（config.yamlより）:
```yaml
aggressive_expansion:
  lower: 1.0
  upper: 1.2
```

**ランダム選択**（シード固定により再現可能）:
```python
係数 = 1.075  # 1.0〜1.2の範囲でランダム選択
```

**目標シェアの計算**:
```
目標シェア = 現状シェア × 係数
         = 0.200 × 1.075
         = 0.215 (21.5%)
```

### ステップ2: 現状数量の計算

```
現状数量 = 1年後市場規模 × 現状シェア
        = 793,800本 × 0.200
        = 158,760本
```

**検証**（実測値）:
- sales_volume合計（oil_gasセグメント）: 122,541本

**差異の理由**:
- 158,760本は「理論値」（市場全体の20%）
- 122,541本は「実績値」（実際の販売データ）
- Step2では理論値を使用

### ステップ3: 目標数量の計算

```
目標数量 = 1年後市場規模 × 目標シェア
        = 793,800本 × 0.215
        = 170,667本
```

**実測値**: 170,652本（小数点処理の違い）

### ステップ4: 競合からの奪取可能数量

**competitor_master.csvのデータ**:

| 競合 | シェア | 強度 | 1年奪取率下限 | 1年奪取率上限 | 中央値 |
|------|-------|------|-------------|-------------|--------|
| CompetitorA | 0.30 | strong | 0.000 | 0.010 | 0.005 |
| CompetitorB | 0.25 | moderate | 0.007 | 0.017 | 0.012 |
| CompetitorC | 0.15 | weak | 0.017 | 0.033 | 0.025 |
| CompetitorD | 0.10 | weak | 0.017 | 0.033 | 0.025 |

**計算**（中央値を使用）:

```
CompetitorAから奪取 = 793,800 × 0.30 × 0.005 = 1,191.3本
CompetitorBから奪取 = 793,800 × 0.25 × 0.012 = 2,381.4本
CompetitorCから奪取 = 793,800 × 0.15 × 0.025 = 2,976.8本
CompetitorDから奪取 = 793,800 × 0.10 × 0.025 = 1,984.5本

合計奪取可能数量 = 1,191.3 + 2,381.4 + 2,976.8 + 1,984.5
                = 8,534本
```

**実測値**: 8,533本（四捨五入の違い）

### ステップ5: 最大可能数量の計算

```
最大可能数量 = 現状数量 + 奪取可能数量
            = 158,760本 + 8,533本
            = 167,293本
```

### ステップ6: 実現可能性チェック

```
目標数量: 170,652本
最大可能数量: 167,293本

超過量 = 目標数量 - 最大可能数量
      = 170,652 - 167,293
      = 3,359本 ❌
```

**実測値で検証**:

- **増加: +48,111本**（+39.3%）

この増加分が拠点A/Bに配分されるため、拠点Bの負荷が増大。

#### 理由2: 拠点Bは既に高稼働

## まとめ: 3つの問題の根拠

### 問題1: oil_gas奪取可能数量超過（3,359本）

**根拠**:
```
目標数量: 793,800 × 0.215 = 170,652本
現状数量: 793,800 × 0.200 = 158,760本
奪取可能: 8,533本
最大可能: 158,760 + 8,533 = 167,293本
超過: 170,652 - 167,293 = 3,359本
```

### 問題2: 拠点B生産能力超過（12,127本）

**根拠**:
```
拠点B目標数量: 216,127本
拠点B生産能力: 204,000本
超過: 216,127 - 204,000 = 12,127本
```

**原因**: 現状で既に超過（+21,723本）、目標でも超過継続

### 問題3: 総販売目標不足（27,385本→46,535本）

**Step2時点**:
```
目標合計: 476,615本
総販売目標: 504,000本
不足: 27,385本
```

**Step3調整後**:
```
調整後合計: 457,465本
総販売目標: 504,000本
不足: 46,535本（削減により悪化）
```

**原因**: withdrawal/reduction戦略による構造的縮小

**解決**: Step4の最適化で拠点A余力活用+高粗利製品集中により504,000本達成
