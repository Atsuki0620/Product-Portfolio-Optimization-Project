# 利益最大化のための製品構成比率分析プロジェクト

このリポジトリは、粗利最大化を目的とした製品ポートフォリオの構成比率最適化を検討するための作業スペースです。担当者ごとに独立したサブフォルダで検証・分析を行い、手法確立後に本番規模へ拡張します。

## 方針
- 各担当者は自分専用のフォルダ配下で作業してください（例: `analyst_a/`）。
- サンプルデータ（20製品×8セグメント×2拠点）で手順を固めた上で、200製品規模への拡大を目指します。
- 粗利最大化を目的に、生産能力、需要（過去3年平均）、拠点間の原価差を考慮した分析を実施します。

## 参考情報
- 背景や分析ステップ、前提条件はプロジェクト仕様書に従います。
- 実行コマンドやテスト結果は各担当フォルダ内に記録してください。
